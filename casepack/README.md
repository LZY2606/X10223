# 胶道标尺离线案例包

共 8 个场景：

- `baseline.png` — 基线：像素级来源完整的正常胶：原图、拍摄方向、曝光、ladder 标称、lane 边界、条带中心全部保留像素级来源。
- `rotation.png` — 反例：拍摄方向旋转 90°：只改动拍摄方向：原始 PNG 被顺时针旋转 90° 拍摄，必须声明 rotationDeg 恢复迁移向下，影响被限制在坐标基准层。
- `curved_lanes.png` — 反例：“微笑”弯曲泳道：泳道呈弯曲；同一像素 y 的两条带分子量不同。必须沿 lane 曲线弧长归一化，局部标尺带有效区域。
- `ladder_missing.png` — 反例：ladder 缺带：ladder 第 4 槽（500bp）缺带；对齐须跳过该槽，缺带两侧分段插值，缺带点不参与拟合。
- `saturation.png` — 反例：饱和条带：lane_3 两条带峰被削平（255）；饱和带只能标为候选或区间，不给唯一断言。
- `overlap.png` — 反例：两条带重叠：lane_6 两条带迁移极近发生重叠；无法唯一决定时保留全部合法候选。
- `nonmonotonic.png` — 反例：非单调 ladder 标尺：只改动 ladder 标称值这一直接来源：标称序列出现违背“迁移越大分子量越小”的倒置，标尺语义无解。
- `revision_local_failure.png` — 反例：修订后局部失效：修订 lane_2 一条带的像素中心，使其局部依赖失效；只该带与受影响推断失效，其余结论保持。

所有领域量携带单位/坐标基准；原始表示保留在 JSON 中。
